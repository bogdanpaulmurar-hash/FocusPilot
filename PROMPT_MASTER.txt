PROMPT MASTER PENTRU GENERARE SI CONTINUARE FOCUSPILOT
=========================================================

Nume Tool: FocusPilot
Descriere: Tool de sistem rezident (Always Awake) cu meniu in Windows System Tray si formatare conditionala vizuala (stil Excel) peste pagini web de browser si aplicatii desktop pe 3 monitoare, cu repere vizuale proeminente (chenar rosu, sageata indicatoare pulsanta, badge-uri de avertizare).

CERINTE CHEIE:
1. Porneste fara CMD (pythonw.exe / .pyw / VBS launcher).
2. Ruleaza permanent in tray (cu pystray) si include:
   - Deschide Dashboard / Configurator
   - Creeaza conditie / regula noua
   - Submeniu cu lista conditiilor existente (toggle activ/inactiv, editare)
   - Pauza / Reluare monitorizare
   - Testeaza repere vizuale (Show demo overlay)
   - Setari (Start with Windows, Hide on launch, Keep PC awake)
   - Iesire
3. Formatare conditionala (stil Excel):
   - Criterii: Titlu fereastra, URL browser, Nume proces (chrome, edge, etc.), Text cautat, Regex.
   - Actiuni vizuale: Chenar rosu / personalizabil, fundal semitransparent, sageata rosie atragatoare (stanga/dreapta/sus/jos/animata), badge de avertizare text.
   - Suport pe 3 monitoare: Overlay transparent Windows click-through (WS_EX_TRANSPARENT | WS_EX_LAYERED) ca sa nu blocheze click-urile utilizatorului.
   - Suport suplimentar pentru Browser prin injectare Playwright si generator de Userscript (Tampermonkey) pentru stilizare directa a DOM-ului HTML.
4. GUI de inalta calitate cu paleta corporate Siemens:
   - Culori: Petrol (#00646E), Teal (#00A3A6), Accent (#EB780A).
   - Suport complet Light Mode si Dark Mode.
5. Setari standard: Start with Windows in Registry, Hide in tray on start, Keep awake prin Windows SetThreadExecutionState.
6. Selectie Interactiva Inteligenta (v1.2):
   - Selector crosshair pe ecran: ascunde aplicatia, capteaza dreptunghiul si detecteaza automat fereastra reala din Z-Order, procesul (ex: chrome.exe / msedge.exe) si coordonatele exacte.
   - Dropdown procese: optiune universala 'browser (Edge + Chrome)' care se activeaza indiferent de browserul folosit, plus lista aplicatiilor deschise in Windows.
   - Testare pozitie exacta: butonul Testeaza deseneaza reperul vizual direct in locatia selectata de utilizator pe ecran.

7. NOU (v2.0) - Arhitectura SilkTest-Like & Mapare Elemente / Butoane:
   - Motivul pentru care overlay-ul transparent clasic esueaza: DWM Windows si accelerarea GPU (DirectX swapchain) din Chrome/Edge fac invizibila fereastra cu cheie de culoare transparenta.
   - Solutie SilkTest pentru Web: Utilizare DevTools / CDP sau injectare Userscript (Tampermonkey) direct in DOM; elementele primesc 'outline: 4px solid red !important' direct in pagina HTML.
   - Solutie SilkTest pentru Desktop: Mapare obiectuala prin Windows UI Automation (AutomationElement, BoundingRectangle, ControlType, AutomationId) si chenare vizuale realizate prin 4 bare TopMost de culoare solida opaca (fara transparentcolor, garantat vizibile).

Pentru detalii complete de arhitectura, cod si roadmap, vezi fisierul PROMPT_MASTER_SPECIFICATION.md din acest folder.
